### 项目功能清单 (v2 - API 定义版)

本文档基于详细的 OpenAPI 规范，旨在精确定义项目的核心功能范围和发布优先级。所有功能均已通过后端 API 进行明确定义。

#### **MoSCoW 方法简介**

*   **M - Must-have (必须有)**: 核心功能，缺少任何一项，产品都无法在当前阶段发布。
*   **S - Should-have (应该有)**: 非常重要的功能，能极大地提升用户体验和产品价值。
*   **C - Could-have (可以有)**: 令人向往但非必要的功能，可在资源允许的情况下开发。
*   **W - Won't-have (这次不会有)**: 在当前项目阶段明确不予开发的功能。

---

### **M - Must-have (必须有)**

*这些是构成产品核心价值、并已在 API 中明确定义的最低功能集。*

*   **用户认证与管理 (User Authentication & Management)**
    *   **功能**: 用户可以通过 Firebase 进行注册和登录，并在应用后端同步创建或更新其个人资料。用户可以获取和修改自己的昵称、头像等基本信息。
    *   **相关 API**: `user.yaml` (`/users/sync`, `/users/me`)

*   **核心学习界面 (Core Learning Interface)**
    *   **功能**: 用户可以查看指定页码的 PDF 内容，并获取与该页面相关的“伴学数据”，包括知识图谱和练习题。
    *   **相关 API**: `companion-data.yaml` (`/pages/{pageNumber}/companion-data`)

*   **互动式知识图谱 (Interactive Knowledge Graph)**
    *   **功能**: 系统能提供以特定页面或知识点为中心的图谱数据。用户可以点击图谱中的节点，进一步探索与其直接关联的其他知识点（一度关系）。
    *   **相关 API**: `companion-data.yaml`, `graph.yaml` (`/graph/nodes/{uuid}/related`)

*   **情境化练习与即时反馈 (Contextual Quizzes & Instant Feedback)**
    *   **功能**: 在学习特定页面时，用户可以获取相关的练习题。提交答案后，系统会立即判断对错，并返回正确答案和官方解释。
    *   **相关 API**: `companion-data.yaml`, `提交答案.yaml` (`/questions/{questionId}/submit`)

*   **多语言内容支持 (Multilingual Content Support)**
    *   **功能**: 系统的核心内容（如题目、选项、解释）在 API 层面支持多种语言 (`en`, `zh`, `es`, `fr`, `de`, `ja`)，为前端实现多语言 UI 提供了数据基础。
    *   **相关 API**: 在多个 API 的 `MultilingualText` schema 中定义。

*   **AI 聊天服务 (AI Chat Service)**
    *   **功能**: 提供一个基础的 AI 聊天接口，支持流式响应和 JSON 格式化输出，可用于各种 AI 辅助功能。
    *   **相关 API**: `ai.yaml` (`/ai/chat`)

### **S - Should-have (应该有)**

*这些功能将使产品从“可用”变为“好用”，是构成完整产品体验的关键。*

*   **智能复习系统 (Intelligent Review System)**
    *   **功能**: 系统基于间隔重复算法，为用户提供到期应复习的题目列表。同时，用户可以随时查看自己所有历史答错过题目的“错题本”。
    *   **相关 API**: `review.yaml` (`/users/me/reviews/due`, `/users/me/wrong-answers`)

*   **个性化学习仪表盘 (Personalized Learning Dashboard)**
    *   **功能**: 为用户提供一个个人统计页面，展示其待复习题目数量、总答题数和整体正确率等核心指标。
    *   **相关 API**: `dashboard.yaml` (`/users/me/dashboard-stats`)

*   **讨论与交流 (Discussion & Communication)**
    *   **功能**: 用户可以针对特定页面或题目发表评论，也可以回复他人评论，形成嵌套的讨论串。支持分页加载顶级评论。
    *   **相关 API**: `comments.yaml` (`/comments`)

*   **AI 交互历史 (AI Interaction History)**
    *   **功能**: 系统会保存用户与 AI 的交互记录。用户可以查看、筛选（如按关联内容）和删除自己的历史记录。
    *   **相关 API**: `chat-interactions.yaml` (`/ai/interactions`)

### **C - Could-have (可以有)**

*这些是“锦上添花”的功能，可以在核心功能稳定后考虑加入。*

*   **学习排行榜 (Leaderboard)**
    *   **功能**: 提供一个排行榜，可以根据总答题数、正确数或准确率对用户进行排名，并支持按时间范围筛选。
    *   **相关 API**: `leaderboard.yaml` (`/leaderboard`)

*   **评论管理 (Comment Management)**
    *   **功能**: 用户可以删除自己的评论。API 数据模型包含支持举报和审核的状态字段，但尚无专门的管理接口。
    *   **相关 API**: `comments.yaml` (`DELETE /comments/{commentId}`)

*   **管理员功能 (Admin Features)**
    *   **功能**: API 中包含供管理员使用的“危险操作”，例如删除知识图谱中的节点及其所有关联关系。
    *   **相关 API**: `graph.yaml` (`DELETE /graph/nodes/{uuid}/related`)

---

### **W - Won't-have (这次不会有)**

*明确声明不做这些功能，有助于团队保持专注。*

*   **用户笔记与高亮**: 不支持用户在教材上直接做笔记或高亮。
*   **复杂的社交网络功能**: 如组建学习小组、私信、用户关注、分享笔记给其他用户等。
*   **支持上传其他文档**: 平台将专注于 *Campbell Biology* 这一核心教材。
*   **原生移动应用 (App)**: 项目初期将集中资源打造世界一流的 Web 网站体验。
*   **教材内容的 AI 翻译**: 不提供对 *Campbell Biology* 教材本身内容的全文机器翻译。
*   **真人在线辅导**: 不包含任何形式的真人教师在线答疑或直播课程。
