### **文档：内容生成引擎项目文件结构 (V1.3 - JSON 工作流)**

**项目目标**: 此项目是一个离线的 Python 工具集，负责调用 Gemini API，根据指定的教材页面生成结构化的练习题，并提供一个基于文件系统的人工审核流程。最终，经过审核的数据将被注入到生产数据库 (Cloudflare D1) 中。

#### **核心设计原则**

- **CLI 驱动**: 提供一个统一的命令行入口 (`main.py`)，让内容管理员可以方便地执行不同的任务。
- **人机协同**: AI 生成的内容（JSON 文件）必须经过人工审核。审核流程通过简单的文件移动完成，无需数据库操作。
- **关注点分离**: 每个模块只做一件事。`workflows` 负责编排业务流程，`prompts` 负责存放核心的 AI 指令。
- **可维护性**: 清晰的目录和模块划分，便于未来添加新的生成任务或修改现有流程。

---

### **项目文件结构**

```
content-generation-engine/
│
├── .env.example                # 环境变量模板文件
├── .gitignore                  # Git 忽略文件列表
├── main.py                     # [核心] 项目的命令行入口 (CLI)
├── README.md                   # 项目说明、安装和使用指南
└── requirements.txt            # Python 依赖包列表
│
├── output/
│   ├── generated_questions/    # [输出] AI 生成的原始 JSON 问题文件
│   │   └── page_101.json
│   └── processed_questions/    # [输入] 经人工审核后，待注入的 JSON 文件
│       └── page_101_approved.json
│
├── prompts/
│   └── generate_questions.md   # 用于生成练习题的 Prompt 模板
│
└── src/
    │
    ├── __init__.py
    ├── clients/                  # 外部服务客户端 (未来扩展)
    │   └── __init__.py
    │
    ├── config.py                 # 配置加载模块
    ├── models/                   # 数据模型 (Pydantic)
    │   └── __init__.py
    │
    └── workflows/
        ├── __init__.py
        ├── generate_questions.py # “生成问题”工作流
        └── seed_approved_data.py # “注入已审核数据”工作流
```

### **文件/目录职责详解**

- **`main.py` (命令行入口)**: 内容管理员唯一需要交互的文件，通过 Typer 提供 CLI 命令。

  - **核心命令**:
    - `generate-questions`: 为指定页面范围生成练习题，并将结果以 `page_XXX.json` 的格式保存在 `output/generated_questions/` 目录下。
    - `seed-questions`: 将 `output/processed_questions/` 目录下的所有 JSON 文件注入到 Cloudflare D1 数据库。

- **`output/` (数据目录)**: 这是“人机协同”的核心区域。
  - `generated_questions/`: AI 生成的原始 JSON 文件存放于此。文件名与页码对应。
  - `processed_questions/`: 生物学专家从 `generated_questions` 目录中取出文件，审查、修改后，放入此目录，即代表“审核通过”。

- **`prompts/`**: 存放所有核心 Prompt 的目录。将 Prompts 作为独立的文本文件进行管理，使得非开发人员也可以方便地查看和优化，而无需改动 Python 代码。

- **`src/workflows/`**: 项目的“大脑”，负责编排业务流程。
  - `generate_questions.py`: 调用 Gemini API，执行“问题生成”任务，并将结果保存到 `output/generated_questions`。
  - `seed_approved_data.py`: 读取 `output/processed_questions` 中的文件，将其转换为 SQL，并注入到 D1 数据库。

这个文件结构清晰地反映了基于 JSON 文件的审核工作流，简化了数据处理流程，降低了对数据库中间件的依赖。
