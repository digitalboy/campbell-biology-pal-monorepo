### **2. 图数据模型 (Neo4j) - V2.2**

此模型的核心目标是构建一个能反映生物学知识内在逻辑、历史背景和人物贡献的，支持多语言的国际化知识图谱。

#### **核心设计：多语言与确定性ID**

*   **多语言支持 (无变化)**: 为了优雅地支持多种语言，所有文本属性（名称、描述等）都聚合到 Map/JSON 对象中。示例: `names: {en: "Mitochondrion", zh: "线粒体"}`。
*   **确定性ID (新说明)**: 所有节点（Node）的唯一主键 `id` 是一个根据其人类可读的原始ID（如 "mitochondrion"）通过 `uuidv5` 算法生成的 **确定性UUID**。这确保了即使在不同批次的数据导入中，同一个概念实体也能获得稳定且唯一的ID，便于数据关联和维护。

#### **节点标签 (Node Labels)**

1.  **:Topic**
    *   **用途**: 表示一个宏观的知识领域或章节主题。
    *   **属性**: `id` (String), `names` (Map), `descriptions` (Map)。

2.  **:KnowledgePoint**
    *   **用途**: 表示一个具体的生物学概念、结构或过程。
    *   **属性**: `id` (String), `names` (Map), `definitions` (Map)。

3.  **:Page**
    *   **用途**: 表示教材中的一个具体页面，作为知识点的“定位锚点”。
    *   **属性**: `number` (Integer)。

4.  **:Person (新增)**
    *   **用途**: 表示对生物学发展有贡献的历史人物（如 Mendel, Darwin）。
    *   **属性**: `id` (String), `names` (Map), `descriptions` (Map)。

5.  **:Event (新增)**
    *   **用途**: 表示科学史上的重要事件（如“DNA双螺旋结构的发现”）。
    *   **属性**: `id` (String), `names` (Map), `descriptions` (Map), `date` (String/Date)。

#### **关系类型 (Relationship Types)**

关系类型旨在回答学生在学习中遇到的各种问题。

*   **结构与层级 (无变化)**: `IS_SUBTOPIC_OF`, `MENTIONED_ON_PAGE`
*   **知识性 (无变化)**: `IS_A`, `IS_PART_OF`, `IS_STEP_IN` (带 `step_number` 属性), `CONTRASTS_WITH`, `CONSUMES`, `PRODUCES`, `REGULATES`, `LOCATION_OF`
*   **人物与事件关系 (新增)**:
    *   `CONTRIBUTED_TO`: 连接人物与其贡献的知识点或主题。 e.g., `(:Person)-[:CONTRIBUTED_TO]->(:KnowledgePoint)`
    *   `PARTICIPATED_IN`: 连接人物与其参与的科学事件。 e.g., `(:Person)-[:PARTICIPATED_IN]->(:Event)`
    *   `LED_TO`: 连接事件与其导致的知识发现或新理论。 e.g., `(:Event)-[:LED_TO]->(:KnowledgePoint)`

#### **查询示例**

获取一个知识点的简体中文名称，并查询是哪位科学家对其有贡献：
```cypher
MATCH (p:Person)-[:CONTRIBUTED_TO]->(kp:KnowledgePoint {id: '...' /* a specific kp id */})
RETURN kp.names.zh AS knowledge_point_name, p.names.zh AS contributor_name
```
